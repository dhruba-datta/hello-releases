# Hello downloads

Release files for **Hello**, free and private voice dictation and meeting notes for Mac.

**Get Hello at [hello.minutecampus.com](https://hello.minutecampus.com).**

- Requires a Mac with Apple silicon (M1 or newer) and macOS 15 or newer.
- Open `Hello.dmg` and drag Hello into Applications.
- The first time you open it, macOS asks you to confirm: open System Settings → Privacy &
  Security and click **Open Anyway** next to Hello. You only do this once.
- Hello updates itself from here. Check any time from the menu bar icon → Check for Updates.

This repository holds release files only.
